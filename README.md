# 🛠️ העסק שלי – אפליקציה להנדימן

אפליקציה לטלפון לניהול לקוחות, עבודות, גבייה ותזרים מזומנים. **עובדת גם בלי אינטרנט.** כל המידע נשמר רק בטלפון ולא נשלח לשום שרת.

## מה יש באפליקציה
- **פניות ועבודות**: כל שיחה נרשמת כפנייה (בבירור / נסגר / לא נסגר + סיבה). אפשר לראות כמה התקשרו וכמה מהם סגרו.
- **לקוחות**: שם, טלפון, כתובת, מוצא (ישראלי / אמריקאי / אנגלי / חוצניק), מאיפה הגיע (ווצאפ / המלצה וממי / עיתון…). הלקוח מסומן אוטומטית כחדש או חוזר.
- **השלמה מהזיכרון**: כשמתחילים להקליד שם, טלפון או כתובת, קופצים לקוחות קיימים, ובחירה ממלאת את כל הפרטים.
- **כסף בכל עבודה**: כמה גבית, חומרים, הוצאות נוספות, רווח גולמי, ותשלומים (מלא או חלקי, מזומן / ביט / העברה…).
- **שולם / לא שולם**: תגית ליד כל עבודה, מסך חובות, ותזכורת תשלום בווצאפ בלחיצה.
- **סיכומים** יומיים, שבועיים, חודשיים ושנתיים, **בלוח הלועזי ובלוח העברי**: פניות, סגירות, הכנסות, חומרים, רווח גולמי, כמה נגבה בפועל, פילוח לפי מקור ומוצא, רווח נקי ומעשר.
- **תזרים עסקי**: מזומן וחשבון עסקי בנפרד. תשלומים מלקוחות וחומרים נכנסים אוטומטית, ואפשר לבצע משיכה לפרטי.
- **תזרים אישי** נפרד.
- **זיהוי שיחה נכנסת**: מראה אם המתקשר לקוח מוכר (כולל היסטוריה וחוב) או לקוח חדש, עם רשימת שאלות לבירור.
- **ייבוא מגוגל שיטס**: מקובץ CSV, מקישור או בהעתק-הדבק. העמודות מזוהות אוטומטית, ואם מייבאים פעמיים אותה שורה היא לא תיכנס שוב.
- **גיבוי ושחזור** לקובץ, וייצוא לאקסל.
- כפתורים לחיוג, ווצאפ וניווט בווייז.

## איך מעלים לטלפון
האפליקציה היא אתר סטטי בלי שרת. צריך לפרסם אותה פעם אחת בכתובת https:

**GitHub Pages:** בהגדרות הריפו ← Pages ← Source: `Deploy from a branch` ← בוחרים את הענף והתיקייה `/ (root)`. אחרי דקה מקבלים כתובת בסגנון `https://<user>.github.io/Clients-business-/`.
(בריפו פרטי GitHub Pages דורש מנוי בתשלום. אפשר במקום זה לגרור את התיקייה ל-[Netlify Drop](https://app.netlify.com/drop).)

אחר כך פותחים את הכתובת בטלפון, ובכרום בוחרים ⋮ ← **"התקן אפליקציה"**. מאותו רגע האפליקציה עובדת גם בלי קליטה.

> ⚠️ המידע שמור רק בטלפון. כדאי לעשות **גיבוי** פעם בשבוע (הגדרות ← גבה עכשיו) ולשלוח את הקובץ לעצמך בווצאפ או לשמור אותו בדרייב.

## חיבור לשיחות נכנסות (אנדרואיד)
1. מתקינים **MacroDroid** מחנות Play.
2. טריגר: *Call Incoming*.
3. פעולה: *Open Website* עם הכתובת `https://<הכתובת שלך>/?phone=[call_number]`
4. בכל שיחה נכנסת נפתח מסך זיהוי הלקוח.

באייפון אין אפשרות לזיהוי אוטומטי. לוחצים על 📞 ומקלידים את המספר.

## ייבוא הטבלה מגוגל שיטס
בגיליון: פותחים את הלשונית (2025 או 2026) ← **קובץ ← הורדה ← CSV**. באפליקציה: הגדרות ← ייבוא מגוגל שיטס ← בוחרים את הקובץ ← בודקים שהעמודות הותאמו נכון ← ייבא. חוזרים על זה לכל לשונית.
