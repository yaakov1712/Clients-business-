# 🛠️ העסק שלי – אפליקציה להנדימן

אפליקציה לטלפון לניהול לקוחות, עבודות, יומן, חומרים, שעות עבודה ותזרים מזומנים. **עובדת גם בלי אינטרנט.** כל המידע נשמר רק בטלפון ולא נשלח לשום שרת.

## מה יש באפליקציה
- **פניות ועבודות**: כל שיחה נרשמת כפנייה (בבירור / נסגר / לא נסגר + סיבה). אפשר לראות כמה התקשרו וכמה מהם סגרו.
- **לקוחות**: טלפון, כתובת, מוצא (ישראלי / אמריקאי / אנגלי / חוצניק), ומאיפה הגיע (ווצאפ / המלצה וממי / עיתון…). חדש או חוזר מסומן אוטומטית.
- **השלמה מהזיכרון**: כשמתחילים להקליד שם, טלפון או כתובת, לקוחות קיימים קופצים, ובחירה ממלאת את כל הפרטים. גם חנויות ותיאורי עבודה נשמרים.
- **כסף בכל עבודה**: גבייה, חומרים, רווח גולמי, תשלום מלא או חלקי (מזומן / ביט / העברה…) וסימון **שולם / לא שולם**. מסך חובות עם תזכורת בווצאפ.
- **יומן** כמו גוגל יומן: חודש / שבוע / יום, עם שעות, צבעים, תאריך **עברי ולועזי** וחגים. עבודות מופיעות ביומן בצבע לפי מצב התשלום.
- **חומרים וקניות**: כמה קניתי, באיזו חנות, איך שולם, ובכמה בכל חנות (חודשי ושנתי).
- **שעות עבודה**: מתי נכנסתי ללקוח ומתי שמתי באוטו, וכמה זמן נסעתי לחנות וחזרתי. טיימר בלחיצה אחת במסך הראשי, ורווח לשעה.
- **סיכומים** יומיים, שבועיים, חודשיים ושנתיים, בלוח הלועזי ובלוח העברי.
- **תזרים עסקי** (מזומן וחשבון עסקי) ו**תזרים אישי** בנפרד.
- **מי מתקשר?** מזהה לפי מספר אם זה לקוח מוכר (כולל חוב והיסטוריה) או לקוח חדש.
- **ייבוא מאקסל**, כולל קריאת צבעים (כחול = שולם, כתום = לא שולם), ו**השלמת נתונים** שחסרים.
- גיבוי ושחזור, ייצוא לאקסל.

## איך מעלים לטלפון
האפליקציה היא אתר סטטי בלי שרת. מפרסמים אותה פעם אחת בכתובת https, למשל **GitHub Pages**: Settings ← Pages ← Source: `Deploy from a branch` ← בוחרים את הענף והתיקייה `/ (root)`. (בחשבון חינמי הריפו צריך להיות ציבורי. המידע שלך לא נמצא בריפו, רק הקוד.)

באייפון: פותחים את הכתובת ב**ספארי** ← כפתור שיתוף ← **הוסף למסך הבית**. מעכשיו פותחים מהאייקון, והכל עובד גם בלי קליטה.

> ⚠️ באייפון, המידע של האפליקציה מהאייקון נפרד מהמידע בספארי. תמיד עובדים מהאייקון, וגם מבצעים את הייבוא משם.
> ⚠️ המידע שמור רק בטלפון. מומלץ **גיבוי** פעם בשבוע (עוד ← גיבוי ושחזור).

## ייבוא הטבלה מאקסל / גוגל שיטס
1. שומרים את הגיליון כקובץ **.xlsx** ומוודאים שהוא נמצא ב"קבצים" בטלפון.
2. באפליקציה: עוד ← ייבוא מאקסל ← בחר קובץ ← בודקים את התצוגה המקדימה ← ייבא.
3. האפליקציה קוראת: תאריך, שם הלקוח, תיאור, סכום, חומרים, מקור הגעה, מוצא, אופן תשלום, שעות והערות. צבע התא של שם הלקוח קובע אם שולם.
4. מייבאים שוב בלי חשש: שורות שכבר קיימות לא מוכפלות. אפשר גם "עדכן הכל מחדש", ועבודות שערכת באפליקציה לא נדרסות.
5. נתונים חסרים (תאריך משוער, סכום, תיאור, מקור הגעה, טלפון, כתובת…) מופיעים ב"השלמת נתונים" ואפשר למלא אותם בקלות.

> קובץ האקסל לא נשמר בריפו (`.gitignore`), כך שפרטי הלקוחות שלך לא עולים ל-GitHub.

## זיהוי שיחה נכנסת
- **אנדרואיד**: דרך MacroDroid (הוראות בהגדרות באפליקציה).
- **אייפון**: אפל לא מאפשרת זיהוי אוטומטי. מעתיקים את המספר מאפליקציית הטלפון ולוחצים "הדבק מספר" במסך "מי מתקשר?".
